---------------------------------------------------------------------
2. 런처에 포함하지 않고, 실행 중에 각 공식 출처에서 받는 것
---------------------------------------------------------------------

[Android SDK Platform-Tools (ADB)] 37.0.0
  - 런처는 ADB를 함께 배포하지 않습니다. Quest 연결에 필요할 때 사용자에게 Google의
    Android SDK 약관(https://developer.android.com/studio/terms)을 보여 주고, 사용자가 동의한
    경우에만 Google 공식 서버에서 받아 SHA-256을 확인한 뒤 사용합니다.
    받은 파일과 함께 Google의 NOTICE.txt 가 보관됩니다.
  - 이미 PC에 있는 ADB(다른 ZECOLE 설치기, SideQuest, Android SDK)가 있으면 그것을 씁니다.

[Meta VR CLI (metavr.exe)]
  - Meta VR Glasses FoV Tester 의 '다른 게임에 적용' 기능에서만 사용합니다. 함께 배포하지 않으며,
    사용자 확인 후 Meta 공식 서버에서 받아 Meta가 알려 주는 SHA-256으로 검증합니다.
  - 이용 약관: https://developers.meta.com/vr/licenses/

[한글패치에 포함된 글꼴]
  - 나눔고딕 · Pretendard · Noto Sans KR · IBM Plex (모두 SIL Open Font License 1.1)
  - 저작권 표시와 라이선스 전문: Fonts-OFL.txt

[각 한글패치 · VR 도구 파일]
  - 런처가 설치하는 한글패치와 도구는 각 GitHub 저장소(github.com/zecole-vr)의 릴리스에서 받으며,
    번역·글꼴(예: 나눔고딕 OFL) 등은 각 저장소의 라이선스와 고지를 따릅니다.

[Pretendard 글꼴]
  - 런처 화면이 jsDelivr CDN에서 불러와 표시합니다(파일은 포함하지 않음).
  - 라이선스: SIL Open Font License 1.1 — https://github.com/orioncactus/pretendard

[게임 이미지 · 영상 썸네일]
